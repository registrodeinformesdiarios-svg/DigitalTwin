Conexiones del ecosistema

Enlaza esta plataforma con tus otras herramientas. Cada una recibe el proyecto activo por el parámetro ?proyecto=, igual que tu tablero actual. Déjalas vacías si aún no aplica — los botones quedarán como provisión.

Se abrirá como {base}?proyecto={proyecto}&actividad={id}
Se abrirá como {base}?proyecto={proyecto}&tema={tema}&fecha={fecha} (tema = grupo de la actividad)
Se abrirá como {base}?proyecto={proyecto}&sim={tipo} (tipo = colada o izaje)
Si lo dejas vacío se usa una versión normalizada del nombre del proyecto.
